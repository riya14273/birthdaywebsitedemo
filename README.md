# 🎂 Personalized Birthday Wish Website

A modern, interactive, and responsive Birthday Wishes generator built with clean **HTML5, CSS3, and Vanilla JavaScript**.

---

## 🌟 Key Features
- 📸 **Photo Upload & Live Preview**: Real-time image preview using JavaScript `FileReader`.
- ✍️ **Custom Name & Message**: Fully customizable with a quick message suggestion assistant.
- 🎨 **5 Color Themes**: Blush Pink, Royal Purple, Ocean Blue, Golden Sparkle, and Romantic Floral.
- ⏳ **Dramatic 3-Second Countdown**: Countdown reveal curtain before showing the celebration page.
- 🎂 **Interactive Cake with Candles**: Tap or click the cake to blow out candles and make a wish!
- 🎁 **Secret Gift Box**: Click to reveal a hidden personalized surprise message.
- 🎶 **Birthday Music & Web Audio Synthesizer**: Plays birthday music with an offline synthesizer fallback.
- 🎊 **Canvas Confetti System**: Smooth particle physics celebration effects.
- 📥 **Greeting Card Download**: Download high-quality greeting card images powered by `html2canvas`.
- 🔗 **Web Share API**: Native device sharing with automatic clipboard fallback.

## 🚀 How to Run in Visual Studio Code (VS Code)

### Method 1: Using Live Server (Recommended)
1. Open **Visual Studio Code**.
2. Go to **File -> Open Folder...** and select this `birthday-wish-website` folder.
3. If you don't already have it installed, open the Extensions tab (`Ctrl+Shift+X`) and search for **"Live Server"** by *Ritwick Dey*, then click **Install**.
4. Right-click on [index.html](file:///c:/Users/Riya%20Dubey/Downloads/birthday-wish-website/index.html) and select **"Open with Live Server"**.
5. The website will open in your default browser at `http://127.0.0.1:5500/`.

### Method 2: Direct Browser Launch (No Extensions Needed)
1. Open the project folder in your Windows File Explorer:
   `C:\Users\Riya Dubey\Downloads\birthday-wish-website`
2. Double-click [index.html](file:///c:/Users/Riya%20Dubey/Downloads/birthday-wish-website/index.html) to open it directly in Chrome, Edge, Brave, or Firefox.
3. Everything runs locally in the browser with **no backend or server setup required**.
